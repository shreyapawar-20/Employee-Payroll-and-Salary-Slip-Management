# Employee Payroll & Salary Slip Management System

## Project Overview
This project is an Excel-based Employee Payroll Management System designed to manage employee information, calculate monthly salaries, track attendance and generate individual employee salary slips.

## Dataset
- 5,000 employee records
- 28 columns
- Employee information, department, job role and location
- Attendance, salary and overtime details

## Key Features
- Employee Payroll Data Management
- Automated Salary Calculations
- Attendance and Overtime Tracking
- Basic Salary, HRA and DA Calculations
- PF and Professional Tax Deductions
- Gross Salary and Net Salary Calculation
- Department-wise Salary Analysis
- Employee-wise Automated Salary Slip
- Payroll Summary with KPI Metrics

## Excel Concepts Used
- Excel Formulas and Functions
- XLOOKUP
- IF and Arithmetic Formulas
- Excel Tables
- Pivot Tables
- Pivot Charts
- Data Analysis and Reporting

## Tools Used
Microsoft Excel

## Project File
`Payroll.xlsx`

## Objective
To simplify employee payroll management, reduce manual calculations and generate accurate salary reports for business operations.
